# 💎 Aurielle Jewellery

A modern, feature-rich jewellery e-commerce landing page platform ✨.  
Crafted with passion and precision to deliver a seamless shopping experience.  

---

## 🌟 Features

- 📱 **Responsive & Elegant UI** – optimized for all devices  
- 🛍️ **Product Catalog** – filtering & search for easy discovery  
- 🔐 **Secure Authentication** – powered by JWT  
- 🛒 **Shopping Cart & Checkout** – smooth and intuitive flow  
- 📦 **Order Management** – track and manage purchases  
- 🖥️ **Admin Dashboard** – inventory & sales insights  

---

## 🛠️ Tech Stack

- **Frontend:** ⚛️ React, Redux, Tailwind CSS  
- **Backend:** 🟢 Node.js, Express.js  
- **Database:** 🍃 MongoDB  
- **Authentication:** 🔑 JWT  
- **Deployment:** 🐳 Docker, ▲ Vercel / ☁️ Heroku
